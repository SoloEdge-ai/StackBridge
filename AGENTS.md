# Agent instructions

## Agent skills

### Issue tracker

Issues and PRDs are tracked in GitHub Issues for `SoloEdge-ai/StackBridge`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five canonical triage roles with their default label names. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses the single-context layout: `CONTEXT.md` at the root and system-wide ADRs under `docs/adr/`. See `docs/agents/domain.md`.
